# 에듀이노 통합 업무관리 프로그램 (초안)

에듀이노 사내 업무를 한곳에 모은 통합 업무관리 프로그램의 초안입니다.
**사내 접속코드**로 로그인 → 좌측 메뉴에서 부서·기능 선택 → 사용하는 사내 프로그램 형태입니다.
상단에는 사내 연동 서비스(에듀이노몰·카페24 관리자 등) **바로가기 링크**가 있으며, 좌측 상단 **로고를 누르면 인트로 후 홈으로** 이동합니다. (링크는 `config.js`의 `QUICK_LINKS`에서 관리)

> **초안 단계**: DB·백엔드 없이 브라우저 안에서만 동작합니다. (설정·데이터는 이 PC의 `localStorage`에 저장)
> 실제 연동 시 `assets/js/config.js`(접속코드·플랫폼)와 인증/저장 로직만 API로 교체하면 됩니다.

## 실행 방법

빌드 도구가 필요 없습니다.

```bash
python3 -m http.server 8080
# http://localhost:8080 접속
```

- **접속코드**: `robodyne12` (10자리, `config.js`에서 변경)
- 최초 접속 시 **이 PC의 기기 이름**을 한 번 지정합니다(예: `MD-PC-01`). 브라우저는 실제 윈도우 PC 이름을 읽을 수 없어 이렇게 대체하며, 지정한 이름이 상단바·상태바에 표시됩니다.

## 화면 흐름

```
index.html (접속코드 로그인 + 기기 이름 등록)
    └─ app.html  (앱 셸: 좌측 사이드바 + 상단바 + 콘텐츠 + 상태바)
```

앱 셸은 SPA 형태로, 좌측 메뉴 클릭 시 콘텐츠 영역만 바뀝니다(해시 라우팅).

| 부서 | 기능 | 상태 |
|------|------|------|

| **CS** | 상담 메모 & 일일 결산 (구글 시트 연동) | ✅ 동작 |
| **MD** | 상품 데이터 관리 도구 (엑셀/CSV 일괄편집) | ✅ 동작 (기존 도구 임베드) |
| **MD** | 상세이미지 변환기 | ✅ 동작 |
| **MD** | 입점사 발주 (상품코드 자동채움) | ✅ 동작 |

### CS · 상담 메모 & 일일 결산

통화 중 3초 안에 기록하고(Ctrl+Enter 저장) 구글 시트로 자동 동기화합니다. (이중 입력 제거)

- **빠른 입력**: 문의유형 토글([상품추천][후불][견적][기타]) · 담당자(마지막값 기억) · 연락처/상품(선택) · 메모(필수) · 콜백 체크. 저장 시 폼 즉시 초기화(유형·담당자 유지). 키보드만으로 입력→저장 가능.
- **오늘 기록**: 최신순 카드, 유형 필터, 수정/삭제, 동기화 상태 배지.
- **일일 결산**: 날짜별 총건수·유형별·담당자별·콜백 미완료 집계, 결산 텍스트 복사.
- **구글 시트 연동**: Apps Script 웹앱(`doPost`)으로 전송. 엔드포인트 URL은 설정 화면에서 입력(하드코딩 없음). **실시간/일괄** 전송, 전송 실패 시 로컬 보존·재시도(데이터 무손실). 레코드는 `id` 기준 **upsert**라 재전송해도 중복 없음.
- **연동 코드**: 저장소 루트 [`google-apps-script.gs`](google-apps-script.gs) 를 시트의 Apps Script에 붙여넣고 웹 앱으로 배포하면 바로 연동됩니다.
- **노션 연동**: 저장/전송을 destination 추상화(`DESTINATIONS`)로 설계 — 이후 노션 대상만 추가하면 됩니다. (현재 인터페이스만, `cs-notes.js`)

레코드 스키마: `{ id, createdAt, type, agent, contact, product, memo, callback, syncedAt }`

### MD · 입점사 발주 (상품코드 자동채움)

입점사 발주 시 **상품코드만 입력하면** 나머지가 자동으로 채워집니다.

- **자동채움**: 자체상품코드 → 입점사명·정산구분·품명(구글시트용) + 배송비·**무료배송조건**(이카운트/확인용). 코드 입력 후 Enter로 발주 목록에 추가. `A~E`로 시작하는 자체상품코드는 **자사** 상품으로 자동 표기(배송비 3,000원).
- **구글시트용 출력**: 발주표 컬럼 순서(`ORDER_SHEET_COLS`)대로 → 복사(TSV)·CSV·Apps Script 자동전송.
- **이카운트용 배송비**: 입점사(거래처)마다 배송비 1줄 자동 생성, 단가(vat포함)→공급가·부가세 ÷11 자동 분리 → 복사·CSV.
- **마스터 관리**: 상품(자체상품코드→입점사·정산구분·품명·배송비 예외) / **입점사 정보**(배송비·무료배송조건·담당자·연락처·발주메일·특이사항) 테이블. 엑셀/구글시트에서 **붙여넣기(TSV) 또는 CSV 불러오기**(헤더 자동 인식). 회사 배송정보 리스트는 [`data/입점사_배송정보.csv`](data/입점사_배송정보.csv)(120개 입점사)를 한 번에 불러올 수 있습니다.
- **배송비 정책**: 입점사별 고정 금액이 기본이며(무료배송조건은 자동 조회에 함께 표시), 특정 상품만 다르면 상품 마스터의 “배송비 예외”로 개별 지정.
- **연동 코드**: [`google-apps-script-orders.gs`](google-apps-script-orders.gs) — 시트에 붙여 웹 앱 배포. (이카운트는 현재 복사/CSV, API 연동은 추후 어댑터로)

### MD · 상세이미지 변환기

상세페이지 통이미지를 **플랫폼별 규격·확장자로 한 번에 변환**해 ZIP으로 내려받습니다.
화면은 **좌우 2분할** — 왼쪽에서 이미지를 업로드·검수(긴 이미지는 스크롤)하고, 오른쪽에서 작업합니다.
대상 플랫폼은 **3열 아이콘 카드**로 클릭해 선택합니다.

- **플랫폼 프리셋** (2026 규격 조사 반영, 설정 탭에서 편집):
  | 플랫폼 | 권장 가로 | 세로/장 | 용량 | 기본 포맷 |
  |---|---|---|---|---|
  | 네이버 스마트스토어 | 860px | 5,000px | 20MB | JPG·PNG |
  | 쿠팡 | 1,000px | 3,000px | 5MB | JPG·PNG |
  | 11번가 | 800px | 무제한 | 10MB | JPG |
  | G마켓 | 860px | 4,000px | 10MB | JPG |
  | 에듀이노 쇼핑몰 | 860px | 무제한 | — | JPG·PNG·WEBP |
- **출력 포맷**: JPG / PNG / WEBP + 원본 통이미지 포함 옵션
- **긴 이미지 분할**: 자동(플랫폼 세로 제한 기준, 예: 쿠팡 3,000px) + 수동(이미지에서 자르는 위치 직접 지정)
- **파일명**: `{플랫폼접두어}_{상품명}[_페이지].{확장자}` (예: `쿠팡_아두이노키트_1.jpg`), 플랫폼별 폴더로 정리
- 모든 처리는 브라우저(Canvas) 안에서만 이뤄지며 서버로 전송되지 않습니다.

## 새 기능 추가 방법

1. `assets/js/config.js` 의 `NAV` 에 메뉴 항목 추가 (`key`, `name`)
2. `assets/js/modules/<부서>.js` 에서 `MODULES['<key>'] = { title, icon, render(el){...} }` 등록
3. `app.html` 에 해당 모듈 스크립트 `<script>` 추가
