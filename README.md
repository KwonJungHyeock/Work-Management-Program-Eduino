# Eduino Works — 통합 업무관리 프로그램 (초안)

에듀이노 사내 업무를 한곳에 모은 통합 업무관리 프로그램의 초안입니다.
**사내 접속코드**로 로그인 → 좌측 메뉴에서 부서·기능 선택 → 사용하는 사내 프로그램 형태입니다.

> **초안 단계**: DB·백엔드 없이 브라우저 안에서만 동작합니다. (설정·데이터는 이 PC의 `localStorage`에 저장)
> 실제 연동 시 `assets/js/config.js`(접속코드·플랫폼)와 인증/저장 로직만 API로 교체하면 됩니다.

## 실행 방법

빌드 도구가 필요 없습니다.

```bash
python3 -m http.server 8080
# http://localhost:8080 접속
```

- **접속코드**: `robodyne12` (10자리, `config.js`에서 변경)
- 최초 접속 시 **이 PC의 기기 이름**을 한 번 지정합니다(예: `MD-PC-01`). 브라우저는 실제 윈도우 PC 이름을 읽을 수 없어 이렇게 대체하며, 지정한 이름이 상단바·상태바에 표시됩니다.

## 화면 흐름

```
index.html (접속코드 로그인 + 기기 이름 등록)
    └─ app.html  (앱 셸: 좌측 사이드바 + 상단바 + 콘텐츠 + 상태바)
```

앱 셸은 SPA 형태로, 좌측 메뉴 클릭 시 콘텐츠 영역만 바뀝니다(해시 라우팅).

## 기능 현황

| 부서 | 기능 | 상태 |
|------|------|------|
| **CS** | 답변 템플릿 (분류별 저장/복사/CRUD) | ✅ 동작 |
| **MD** | 상품 데이터 관리 도구 (엑셀/CSV 일괄편집) | ✅ 동작 (기존 도구 임베드) |
| **MD** | 상세이미지 변환기 | ✅ 동작 |
| 디자인 | 에셋 관리 / 배너 문구 | 🕓 개발 예정 |
| 경리 | 매출·매입 집계 / 정산표 | 🕓 개발 예정 (1차 초안 `backup/`에 보존) |

### MD · 상세이미지 변환기

상세페이지 통이미지를 **플랫폼별 규격·확장자로 한 번에 변환**해 ZIP으로 내려받습니다.

- **플랫폼 프리셋** (2026 규격 조사 반영, 설정 탭에서 편집):
  | 플랫폼 | 권장 가로 | 세로/장 | 용량 | 기본 포맷 |
  |---|---|---|---|---|
  | 네이버 스마트스토어 | 860px | 5,000px | 20MB | JPG·PNG |
  | 쿠팡 | 1,000px | 3,000px | 5MB | JPG·PNG |
  | 11번가 | 800px | 무제한 | 10MB | JPG |
  | G마켓 | 860px | 4,000px | 10MB | JPG |
  | 에듀이노 쇼핑몰 | 860px | 무제한 | — | JPG·PNG·WEBP |
- **출력 포맷**: JPG / PNG / WEBP + 원본 통이미지 포함 옵션
- **긴 이미지 분할**: 자동(플랫폼 세로 제한 기준, 예: 쿠팡 3,000px) + 수동(이미지에서 자르는 위치 직접 지정)
- **파일명**: `{플랫폼접두어}_{상품명}[_페이지].{확장자}` (예: `쿠팡_아두이노키트_1.jpg`), 플랫폼별 폴더로 정리
- 모든 처리는 브라우저(Canvas) 안에서만 이뤄지며 서버로 전송되지 않습니다.

## 폴더 구조

```
index.html                 접속코드 로그인 + 기기 등록
app.html                   앱 셸
assets/
  favicon.svg
  css/  theme.css          디자인 시스템(엔터프라이즈 톤)
        shell.css          셸 레이아웃
        login.css          로그인 화면
  js/   config.js          접속코드·플랫폼 프리셋·내비  ← 실서비스 전환 시 교체 지점
        app.js             아이콘·인증(코드/기기)·유틸·MODULES 레지스트리
        shell.js           사이드바/상단바/상태바 렌더 + 라우팅
        zip.js             의존성 없는 ZIP 생성기(store 방식)
        modules/cs.js      CS 답변 템플릿
        modules/md.js      MD 상품도구(iframe) + 상세이미지 변환기
modules/md/product-tool.html   기존 상품 데이터 관리 도구
backup/first-draft/            1차 초안(대시보드·디자인·경리 등) 보존
```

## 새 기능 추가 방법

1. `assets/js/config.js` 의 `NAV` 에 메뉴 항목 추가 (`key`, `name`)
2. `assets/js/modules/<부서>.js` 에서 `MODULES['<key>'] = { title, icon, render(el){...} }` 등록
3. `app.html` 에 해당 모듈 스크립트 `<script>` 추가
