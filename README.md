# Eduino Works — 통합 업무관리 프로그램 (초안)

에듀이노 4개 업무(**CS · MD · 경리 · 디자인**)의 편의기능을 한곳에 모은 통합 업무관리 프로그램의 초안입니다.
직원이 개인 ID/PW로 로그인 → 홈에서 부서/기능 선택 → 기능 사용하는 흐름입니다.

> **초안 단계**: DB·백엔드 없이 브라우저 안에서만 동작합니다. (로그인·입력 데이터는 `localStorage`에 임시 저장)
> 실제 연동은 나중에 `assets/js/data.js`(계정/기능 목록)와 저장 로직만 API로 교체하면 됩니다.

## 실행 방법

빌드 도구가 필요 없습니다. 아래 중 하나로 실행하세요.

- **가장 간단**: `index.html` 을 브라우저로 열기
- **권장(파일 접근 이슈 없이)**: 프로젝트 폴더에서 로컬 서버 실행
  ```bash
  python3 -m http.server 8080
  # 브라우저에서 http://localhost:8080 접속
  ```

## 화면 흐름

```
index.html (로그인)
    → dashboard.html (홈: 내 부서 + 전체 4개 부서 + 공통 기능)
        → modules/<부서>/index.html (부서 편의기능 목록 + 인라인 툴)
```

## 폴더 구조

```
index.html                  로그인
dashboard.html              홈 대시보드
assets/
  css/base.css              공통 디자인 시스템 (샘플 상품툴 토큰 재활용)
  js/
    data.js                 목업 데이터: 직원 계정, 부서, 기능 목록  ← 실서비스 전환 시 여기만 교체
    app.js                  인증/세션(localStorage), 앱바, 공통 유틸(toast/copy/store)
    module.js               부서 페이지 공용 렌더러 (랜딩 + 인라인 툴 라우팅)
modules/
  cs/index.html             CS   · 답변 템플릿(동작)
  md/index.html             MD   · 랜딩
  md/product-tool.html      MD   · 상품 데이터 관리 도구 (기존 도구 이식)
  accounting/index.html     경리 · 매출·매입 집계기(동작)
  design/index.html         디자인 · 파일 이름 일괄변경(동작)
```

## 새 기능 추가 방법

1. `assets/js/data.js` 의 `FEATURES.<부서>` 배열에 항목 추가 (`status:'live'`, `href:'index.html#키'`)
2. 해당 `modules/<부서>/index.html` 에서 툴 객체 `{ title, render(root){...} }` 작성
3. `initModule('<부서>', { 키: 툴객체 })` 에 등록
