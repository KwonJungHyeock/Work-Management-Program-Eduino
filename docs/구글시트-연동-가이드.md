# 구글 시트 2차 백업 연동 가이드

프로그램의 각 업무 기록은 **서버(KV)에 1차 저장**됩니다. 여기에 **구글 시트를 2차 백업**으로 붙여, 프로그램에 문제가 생겨도 데이터가 남도록 합니다.

> 핵심: **Apps Script 웹앱을 한 번만 배포**하면, 모든 모듈이 각자 **탭(sheet)**에 자동으로 쌓입니다.
> (모듈마다 시트를 따로 만들고 싶으면, 스프레드시트를 여러 개 만들어 각 모듈에 다른 URL을 넣어도 됩니다.)

---

## A. 한 번만 하는 준비 (약 3분)

1. **구글 스프레드시트를 하나 새로 만듭니다.** (탭·헤더는 자동 생성되니 비어 있어도 됩니다.)
2. **확장 프로그램 → Apps Script** 를 엽니다.
3. 프로그램 화면(예: `MD › 품절관리 현황 › [시트 연동]`)의 **[Apps Script 코드 복사]** 버튼을 눌러
   나온 코드를 Apps Script 편집기에 **전부 붙여넣고 저장**합니다.
   - 코드 상단 `SHEET_NAME` 은 **비워둔 채로('')** 둡니다 → 각 모듈이 자기 탭에 기록합니다.
4. **(선택·권장) 전체 탭 자동 생성** — 편집기 상단 함수 목록에서 **`setupTabs`** 를 선택하고 **[실행]** 을 누릅니다.
   → 이 스프레드시트에 **CS·MD 8개 탭이 헤더까지 한 번에 생성**됩니다(빈 '시트1'은 자동 정리). 안 해도 첫 저장 때 탭이 자동 생성됩니다.
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행: **나**, 액세스 권한: **모든 사용자** 로 배포합니다. (권한 승인 창이 뜨면 허용)
6. 표시된 **웹 앱 URL** ( `…/exec` 로 끝남 ) 을 복사합니다.

> 코드를 수정하면 반드시 **[배포 관리 → 새 버전 → 배포]** 로 재배포해야 반영됩니다.

---

## B. 각 모듈에 URL 붙여넣기

아래 각 화면에서 **[시트 연동]**(또는 **연동 설정**) 을 열고, A-5의 **같은 URL** 을 붙여넣은 뒤
**[저장] → [연결 테스트]** 를 누릅니다. 이후 저장하는 기록이 서버와 시트에 **동시에** 쌓입니다.

| 모듈 | 위치 | 자동 생성 탭 | 시트 1행(자동 생성 헤더) |
|---|---|---|---|
| CS상담 메모 | CS › CS상담 메모 › 연동 설정 | `CS상담메모` | 날짜·분류·주문경로·연락처·고객유형·주문자/학교/업체명·상품분류·상품코드·내용·답변·상담사 |

- URL은 **팀 공유** 설정이라 한 사람이 저장하면 팀 전체에 반영됩니다(각자 넣지 않아도 됨).
- 시트 **1행(헤더)** 은 첫 전송 때 자동으로 만들어집니다. 열 순서를 바꿔도 헤더 이름으로 정확히 들어갑니다.
- 각 기록은 숨은 **id 열**로 **중복 없이 갱신(upsert)** 됩니다 — 수정·재전송해도 행이 늘지 않습니다.
- 현황판의 **[이번 목록 전체 전송]** 으로 기존에 쌓인 내용을 한 번에 시트로 밀어 넣을 수 있습니다.

### 기존 데이터 백필(과거 기록을 시트로 옮기기)
- **상담 기록 / TS상담 기록** 화면 상단의 **[시트로 전송]**(관리자) 버튼으로, 현재 **기간·필터에 잡힌 서버 누적 기록**을 시트로 한 번에 보냅니다.
  1. 기간을 **[지정]** 으로 넓게 잡습니다(예: 과거 1년). 2. (선택) 상담사·분류 필터. 3. **[시트로 전송]** → 확인.
  - id 기준이라 **여러 번 눌러도 중복이 생기지 않습니다**(이미 있는 행은 갱신).
- 후불/발주·교환/반품·현황판은 각 화면 **[시트 연동] → [이번 목록 전체 전송]** 으로 동일하게 백필합니다.

---

## C. MD 입점사 발주 (통합됨)

입점사 발주도 **같은 통합 코드/배포**로 처리됩니다. `MD › 입점사 발주 › 연동 설정`에 **같은 /exec URL**을 붙여넣으면
발주 내역이 이 스프레드시트의 **`입점사발주` 탭**에 쌓입니다. (발주표는 누적 추가 방식 · 나머지 모듈은 id 기준 갱신)

---

## D. 문제 해결

- **연결 테스트 실패**: 배포 시 액세스 권한이 **모든 사용자** 인지 확인. URL이 `…/exec` 로 끝나는지 확인.
- **응답 확인 불가로 표시**: 구글 보안정책(CORS)상 응답을 못 읽는 경우로, **전송은 정상**입니다(id 기준이라 재전송해도 안전).
- **다른 탭에 들어감**: Apps Script의 `SHEET_NAME` 이 특정 탭으로 고정돼 있는지 확인(비워두면 모듈별 탭 사용).
