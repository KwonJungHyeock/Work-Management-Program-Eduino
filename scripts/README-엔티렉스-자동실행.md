# 엔티렉스(디바이스마트) 크롤러 — 내 PC에서 자동 실행하기

디바이스마트는 **국내 IP**에서만 안정적으로 조회돼서, 이 크롤러는 서버(Vercel)가 아니라
**담당자 PC(사무실 컴퓨터)**에서 돌립니다. 아래대로 한 번만 설정하면 **매일 오전 10시** 자동 실행됩니다.

## 0. 준비물
- Windows PC (실행 시각에 켜져 있어야 함)
- **Node.js LTS** 설치 — https://nodejs.org (설치 후 재부팅 권장)

## 1. 폴더 복사
아래 **4개 파일 + 상품목록**을 PC의 한 폴더(예: `C:\eduino\ntrex\`)에 함께 둡니다.
```
ntrex-price.mjs              ← 크롤러 본체
ntrex-list.json             ← 상품목록(코드·기준가)
run-ntrex.bat               ← 실행기
엔티렉스-자동실행-등록.bat   ← 매일 10시 등록기
.env.example                ← 설정 예시
```
> 이 파일들은 리포지토리 `scripts/` 폴더에 있습니다. 폴더째 복사해도 됩니다.

## 2. 설정 파일(.env) 만들기
`.env.example` 을 같은 폴더에 **`.env`** 라는 이름으로 복사합니다.
(탐색기에서 새 이름을 `.env.` 로 입력하면 만들어집니다.)
내용은 기본값 그대로 두면 되고, `STORE_URL` 만 확인하면 됩니다.

## 3. 수동 테스트 (한 번 확인)
- 먼저 **업로드 없이** 동작만 볼 때: `명령 프롬프트`에서
  ```
  cd C:\eduino\ntrex
  node ntrex-price.mjs --dry --limit=10
  ```
- 실제 실행 확인: `run-ntrex.bat` **더블클릭** → `logs\ntrex-last.log` 열어서 결과 확인.

## 4. 자동 실행 등록 (매일 10:00)
`엔티렉스-자동실행-등록.bat` 을 **마우스 우클릭 → 관리자 권한으로 실행**.
> "등록 완료 — 매일 오전 10:00" 메시지가 뜨면 끝.

- 지금 즉시 한 번 돌려보기: `schtasks /Run /TN "Eduino-NTREX-크롤러"`
- 등록 취소: `schtasks /Delete /TN "Eduino-NTREX-크롤러" /F`

## 5. 결과 확인
앱 **가격비교 → 엔티렉스 → 변동 알림** 에서 **오늘 날짜**의 리포트가 보이면 정상입니다.
(3일 순환이라 하루엔 전체의 약 1/3만 조사 → 3일이면 전 품목 1회전)

## 자주 묻는 것
- **왜 매일 10시인데 안 돌아요?** → 그 시각에 PC가 꺼져 있었거나 로그오프 상태였을 수 있어요.
  자리 비움에도 돌리려면: 작업 스케줄러 → `Eduino-NTREX-크롤러` → 속성 →
  **'사용자가 로그온하지 않아도 실행'** 체크 + 비밀번호 입력.
- **IP가 차단된 것 같아요** → `.env` 의 `NTREX_PROXY` 에 국내 프록시를 넣고 재실행.
  (프록시 사용 시 폴더에서 `npm i undici` 1회 필요)
- **로그는 어디?** → 같은 폴더 `logs\ntrex-last.log`(최근 실행 전체) / `ntrex-history.log`(실행 이력).
